# Sicherheitslücken melden

Du hast eine Schwachstelle in Karriko gefunden? Danke, dass du sie meldest.

## Wie

Bitte **vertraulich** über GitHub melden:
[Sicherheitslücke melden](https://github.com/dresogo/Karriko/security/advisories/new)

Bitte kein öffentliches Issue und keinen Pull Request, solange die Lücke nicht behoben ist.

Hilfreich sind:

- betroffene Adresse, Seite oder Datei
- Schritte zum Nachvollziehen
- was ein Angreifer damit erreichen könnte

Meldungen auf Deutsch oder Englisch.

## Geltungsbereich

- die Web-App unter karriko.de und karriko.dresogo.de
- der Code in diesem Repository (App, Appwrite Functions, `services/passkey-rp`)

Lücken in Diensten Dritter (zum Beispiel Appwrite Cloud) bitte direkt beim jeweiligen Anbieter melden.

## Bitte nicht

- auf Daten anderer Nutzer zugreifen, sie ändern oder löschen
- Tests, die den Betrieb stören (Last, Spam, Massenregistrierungen)
- Social Engineering gegenüber Nutzern oder Betrieben

Diese Datei ist auch die `Policy` aus [`/.well-known/security.txt`](karriko_flutter/web/.well-known/security.txt) (RFC 9116).
